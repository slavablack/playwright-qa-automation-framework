🎭 Playwright QA Automation Framework
A modern test automation framework built with Playwright and TypeScript, following the Page Object Model (POM) design pattern. The project supports UI and API testing, scalable test organization, and automated execution through GitHub Actions.

✨ Features
UI Automation with Playwright
API Testing
TypeScript Support
Page Object Model (POM)
GitHub Actions CI/CD
Reusable Test Utilities
Easy Environment Configuration
🚀 Getting Started
npm install
npx playwright install
npx playwright test
🔄 Continuous Integration
Tests are automatically executed on every push and pull request using GitHub Actions.
